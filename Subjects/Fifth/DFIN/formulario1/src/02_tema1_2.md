# Temas 1 y 2: valor actual, Fisher, obligaciones y acciones

## Valor actual y VAN

$$VA = \sum_{t=1}^{n}\frac{C_t}{(1+r)^t} \qquad\qquad VAN = -C_0 + \sum_{t=1}^{n}\frac{C_t}{(1+r)^t} \qquad\qquad \text{Un periodo: } VAN = -C_0 + \frac{C_1}{1+r}$$

**Tasa de rentabilidad** (un periodo): $\;\dfrac{C_1 - C_0}{C_0} > r \iff VAN > 0$.

**Objetivo financiero:** maximizar el valor de mercado de las acciones, que equivale a aceptar todo proyecto con $VAN > 0$.

## Fundamentos del VAN (modelo de Fisher, dos periodos)

| Concepto | Fórmula |
| :--- | :--- |
| Consumo máximo hoy sin invertir (flujos $B$ hoy y $F$ mañana) | $D = B + \dfrac{F}{1+r}$ |
| Consumo máximo mañana sin invertir | $H = F + B(1+r)$ |
| Línea del mercado de capitales | $C_0 + \dfrac{C_1}{1+r} = W$; pendiente $-(1+r)$ |
| Riqueza con inversión real $I$ que rinde $F_1 = f(I)$ | $W = W_0 - I + \dfrac{F_1}{1+r} = W_0 + VAN$ |
| Consumo máximo hoy (prefiere consumo actual) | $W_0 + VAN = J + JK = K$ |
| Consumo máximo mañana (prefiere consumo futuro) | $F_1 + (W_0 - I)(1+r) = (W_0 + VAN)(1+r)$ |
| Aumento de riqueza en $t=0$ | $VAN$ |
| Aumento de riqueza en $t=1$ | $VAN\,(1+r)$ |
| Pendiente de la curva de inversión | $-(1 + r')$, con $r'$ = rentabilidad marginal ($TIR_{mg}$) |
| Pendiente de la curva de indiferencia | $-(1+\rho)$, con $\rho$ = tasa subjetiva de preferencia temporal |
| Inversión óptima (máximo VAN) | $f'(I) = 1 + r \iff r' = r$ (tangencia) |
| Óptimo de consumo | $\rho = r$ |
| Préstamo y endeudamiento a tipos distintos | Prestamista: $r' = r_p$; prestatario: $r' = r_d$; con $r_d > r_p$ no hay unanimidad |

## Obligaciones (bonos)

| Concepto | Fórmula |
| :--- | :--- |
| Cupón | $C = \text{tipo del cupón} \times VN$ |
| Precio (valor actual) | $P_0 = \sum_{t=1}^{n}\dfrac{C}{(1+r)^t} + \dfrac{VN}{(1+r)^n} = C\,a_{\overline{n}\rvert r} + \dfrac{VN}{(1+r)^n}$ |
| Bono cupón cero | $P_0 = \dfrac{VN}{(1+r)^n}$ |
| Precio con la ETTI (un tipo por plazo) | $P_0 = \sum_{t=1}^{n}\dfrac{C}{(1+r_t)^t} + \dfrac{VN}{(1+r_n)^n}$ |
| Rentabilidad actual | $\dfrac{C}{P_0}$ |
| Rentabilidad al vencimiento ($TIR$, $y$) | $y$ tal que $P_0 = C\,a_{\overline{n}\rvert y} + \dfrac{VN}{(1+y)^n}$ |
| Rentabilidad del periodo de tenencia (1 año) | $\dfrac{C + P_1 - P_0}{P_0}$ |
| Rentabilidad de compraventa a $k$ años | $R$ tal que $P_0 = \sum_{t=1}^{k}\dfrac{C}{(1+R)^t} + \dfrac{P_k}{(1+R)^k}$ |
| Precio de venta en $k$ | $P_k = C\,a_{\overline{n-k}\rvert r_k} + \dfrac{VN}{(1+r_k)^{n-k}}$ (vida residual $n-k$) |
| Duración de Macaulay | $D = \dfrac{1}{P_0}\sum_{t=1}^{n} t\,\dfrac{C_t}{(1+y)^t}$ |
| Duración modificada | $D^* = \dfrac{D}{1+y}$ |
| Variación aproximada del precio | $\dfrac{\Delta P}{P} \approx -D^*\,\Delta y$ |
| Prima de riesgo de crédito (*spread*) | $y_{\text{empresa}} - y_{\text{Estado}}$ (mismo plazo) |

**Reglas:** si el tipo de mercado es igual al cupón, el bono cotiza **a la par**; si es menor, **sobre la par**; si es mayor, **bajo la par**. La rentabilidad actual solo coincide con la rentabilidad al vencimiento a la par. A más plazo y menos cupón, más riesgo de tipo de interés.

**Estructura temporal de los tipos de interés (ETTI):**

$$(1+r_t)^t = (1+r_{t-1})^{t-1}(1+f_{t-1,t}) \qquad\qquad (1+r_m)^m = (1+r_n)^n\,(1+f_{n,m})^{m-n}$$

donde $r_t$ es el tipo de contado (*spot*) a $t$ años y $f$ el tipo a plazo (*forward*) implícito.

## Acciones: modelo de descuento de dividendos

| Concepto | Fórmula |
| :--- | :--- |
| Rentabilidad en un periodo | $r = \dfrac{DIV_1}{P_0} + \dfrac{P_1 - P_0}{P_0}$ |
| Precio con un periodo | $P_0 = \dfrac{DIV_1 + P_1}{1+r}$ |
| Precio con $H$ periodos | $P_0 = \sum_{t=1}^{H}\dfrac{DIV_t}{(1+r)^t} + \dfrac{P_H}{(1+r)^H}$ |
| Precio con horizonte infinito | $P_0 = \sum_{t=1}^{\infty}\dfrac{DIV_t}{(1+r)^t}$ |
| Sin crecimiento | $P_0 = \dfrac{DIV_1}{r}$; $\quad r = \dfrac{DIV_1}{P_0}$ |
| Gordon (crecimiento constante) | $P_0 = \dfrac{DIV_1}{r - g}$; $\quad r = \dfrac{DIV_1}{P_0} + g$ |
| Dividendo con crecimiento | $DIV_t = DIV_1(1+g)^{t-1}$; $\quad DIV_1 = DIV_0(1+g)$ |
| Por fases | $P_0 = \sum_{t=1}^{T}\dfrac{DIV_t}{(1+r)^t} + \dfrac{P_T}{(1+r)^T}$, $\quad P_T = \dfrac{DIV_{T+1}}{r - g_2}$ |
| Precio en $T$ si desde $T+1$ se reparte un BPA constante | $P_T = \dfrac{BPA}{r}$ |

## Crecimiento, beneficio y dividendo

| Concepto | Fórmula |
| :--- | :--- |
| Beneficio por acción | $BPA = \dfrac{\text{Beneficio neto}}{\text{Nº de acciones}}$ |
| Tasa de reparto (*payout*) | $p = \dfrac{DIV}{BPA} = 1 - b$ |
| Tasa de retención o reinversión | $b = \dfrac{\text{Reservas}}{\text{Beneficio}} = 1 - p$ |
| Dividendo | $DIV_t = (1-b_t)\,BPA_t$ |
| Rentabilidad de los fondos propios | $ROE = \dfrac{BPA}{\text{Valor contable por acción}} = \dfrac{BN}{\text{Fondos propios}}$ |
| Crecimiento | $g = b \times ROE$ |
| ROE implícito | $ROE = g/b$ |
| Evolución del valor contable | $VC_{t} = VC_{t-1} + b\,BPA_t$; $\quad BPA_{t+1} = ROE\cdot VC_t$ |
| Evolución del BPA con reinversión perpetua | $BPA_{t+1} = BPA_t + ROE\cdot b_t\,BPA_t = BPA_t(1 + b_t\,ROE)$ |

## Valor actual de las oportunidades de crecimiento (VAOC)

| Concepto | Fórmula |
| :--- | :--- |
| Descomposición del precio | $P_0 = \dfrac{BPA_1}{r} + VAOC$ |
| VAOC por diferencia | $VAOC = P_0 - \dfrac{BPA_1}{r}$ |
| VAOC directo | $VAOC = \sum_t \dfrac{VAN_t}{(1+r)^t}$ |
| Capital reinvertido en $t$ | $I_t = b_t \times BPA_t$ |
| Flujo anual de la reinversión | $F = ROE \times I_t$ |
| VAN de una reinversión perpetua (en $t$) | $VAN_t = -I_t + \dfrac{ROE\cdot I_t}{r} = I_t\left(\dfrac{ROE}{r} - 1\right)$ |
| VAN de una reinversión de $n$ años | $VAN_t = -I_t + ROE\cdot I_t\cdot a_{\overline{n}\rvert r}$ |
| VAOC con Gordon (forma cerrada) | $VAOC = \dfrac{BPA_1(1-b)}{r-g} - \dfrac{BPA_1}{r} = \dfrac{BPA_1\,b\,(ROE - r)}{r\,(r-g)}$ |
| Rentabilidad mínima de una reinversión perpetua | $ROE = r$ (VAN = 0) |

**Ratio beneficio/precio y PER:**

$$\frac{BPA_1}{P_0} = r\left(1 - \frac{VAOC}{P_0}\right) \qquad\qquad PER = \frac{P_0}{BPA_1} = \frac{1}{r} + \frac{VAOC}{BPA_1} \qquad\qquad PER_{\text{Gordon}} = \frac{1-b}{r-g}$$

| Caso | Relación |
| :--- | :--- |
| $ROE > r$ | $VAN > 0$, $VAOC > 0$, $BPA/P < r$, $PER > 1/r$: **acción de crecimiento** |
| $ROE = r$ | $VAN = 0$, $VAOC = 0$, $BPA/P = r$, $PER = 1/r$ (aunque $g>0$) |
| $ROE < r$ | $VAN < 0$, $VAOC < 0$, $BPA/P > r$: reinvertir destruye valor |

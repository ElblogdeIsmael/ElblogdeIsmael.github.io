# Notación {.unnumbered}

| Símbolo | Significado |
| :--- | :--- |
| $r$, $k$ | Coste de oportunidad del capital (tasa de descuento, tasa de capitalización del mercado) |
| $C_0$, $I_0$ | Desembolso inicial |
| $C_t$, $F_t$, $FNC_t$ | Flujo de caja del año $t$ |
| $a_{\overline{n}\rvert r}$ | Factor de anualidad: valor actual de 1 € al año durante $n$ años al tipo $r$ |
| $BPA$, $DIV$ | Beneficio y dividendo por acción |
| $b$ | Tasa de retención o reinversión; $1-b$ es la tasa de reparto (*payout*) |
| $ROE$ | Rentabilidad de los fondos propios (o de las reinversiones) |
| $g$ | Tasa de crecimiento de beneficios y dividendos |
| $VAOC$ | Valor actual de las oportunidades de crecimiento |
| $t_c$ | Tipo del impuesto sobre sociedades |
| $CAF$ | Cuota de amortización fiscal |
| $FM$ | Fondo de maniobra (capital circulante operativo) |
| $VNC$ | Valor neto contable |
| $Q_i^{ai}$, $Q_i^{di}$ | Flujo de las operaciones antes y después de impuestos |
| $VR_n^{di}$ | Valor residual después de impuestos |
| $\pi$ | Tasa de inflación |

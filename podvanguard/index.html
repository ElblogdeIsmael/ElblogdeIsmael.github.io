PodVanguard

Centro de Mando Web de Alto Rendimiento para Contenedores Docker & Kubernetes Pods en Linux.

curl -fsSL https://raw.githubusercontent.com/Ismael-Sallami/pod-vanguard/main/install.sh | bash
Repositorio en GitHub Ver Arquitectura

¿Por qué PodVanguard?

Los entornos modernos de desarrollo en Linux a menudo requieren controlar contenedores Docker locales y pods de Kubernetes simultáneamente, pero las herramientas tradicionales o bien son interfaces de consola limitadas o pesados dashboards web basados en Node.js/Python que consumen cientos de megabytes de memoria de fondo.

PodVanguard revoluciona este paradigma: se compila en un único binario nativo en Rust de solo 4.5 MB que contiene embebido su propio servidor web reactivo en React 19 (estética Teenage Engineering / Brutalismo Suizo con paleta Carbón Mate y Naranja Seguridad). Cero dependencias en tiempo de ejecución.

[01] Docker & Podman Engine

Comunicación nativa asíncrona mediante sockets UNIX (/var/run/docker.sock). Arranque, detención, reinicio, pausa y eliminación de contenedores con respuesta instantánea.

[02] Kubernetes Pods & Context

Detección automática de ~/.kube/config, inspección de namespaces, pods, contenedores listos, reinicios y nodos. Si no hay clúster activo, opera en modo autónomo sin bloquearse.

[03] Vanguard Sentinel Shield

Motor de auditoría heurística de seguridad que detecta en tiempo real claves privadas (AWS, OpenAI, GitHub PAT, RSA), puertos sensibles expuestos a 0.0.0.0, procesos como root y riesgos OOM sin cuotas de memoria.

[04] Terminal WebSockets PTY

Sesión de terminal interactiva real conectada por WebSocket con emulación de secuencias de escape ANSI completas, control de teclado y redimensionamiento dinámico de ventana.

[05] Lienzo CAD de Topología

Grafo interactivo con nodos arrastrables que visualiza las relaciones vivas entre redes virtuales (Bridge, Host), contenedores, puertos mapeados al host y volúmenes de almacenamiento persistente.

[06] Saneamiento Pruner de Disco

Cálculo exacto del almacenamiento ocupado por contenedores parados, imágenes huérfanas (dangling) y volúmenes sin dependencias, con botón de purga segura en un solo clic.

Línea de Comandos

# Ejecución en el puerto por defecto (9090):
pod-vanguard

# Utilizando el alias corto:
pv

# Abrir automáticamente el navegador predeterminado:
pod-vanguard -p 8080 --open

# Escuchar en todas las interfaces de red del servidor:
pod-vanguard -H 0.0.0.0 -p 9090

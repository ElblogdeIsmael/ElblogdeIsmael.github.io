Un repositorio entero en un solo Markdown

Pega la dirección de un repositorio de GitHub y te devuelvo un único fichero .md con el resumen, el árbol de carpetas y el contenido de cada fichero. Se lo pasas a una IA y te explica el proyecto, lo revisa o te ayuda a cambiarlo. También funciona con repos privados.

No encuentro ese repositorio. Si es privado, pega un token de GitHub con permiso de solo lectura y lo vuelvo a intentar.

Crea uno aquí: en Repository access elige el repo y en Permissions da Contents: Read-only. El token solo se envía a api.github.com y se guarda en esta pestaña hasta que la cierres.

    Cómo se usa
    
    
    
      
    
        
    En la web
    
        
    
          Pega la dirección del repositorio y pulsa Cargar. Verás la lista de
          ficheros que van a entrar: desmarca los que no quieras y pulsa Generar.
          Después copias el Markdown o lo descargas y se lo das a tu IA.
        
    
      
    

      
    
        
    En la terminal
    
        
    Se instala con un solo comando (necesita Node.js 18 o superior):
    
        
    curl -fsSL https://raw.githubusercontent.com/Ismael-Sallami/gittomd/main/install.sh | bash
    
        
    
          Y se usa así: gittomd owner/repo. Si el repo es privado te pregunta
          y te deja iniciar sesión con GitHub. También convierte carpetas locales:
          gittomd .
        
    
      
    

      
    
        
    Qué se deja fuera
    
        
      
          
    • Binarios: imágenes, PDFs, fuentes, comprimidos y parecidos.
      • 
          
    • Ficheros de bloqueo como package-lock.json y ficheros minificados.
      • 
          
    • Carpetas como node_modules y lo que marque .gitignore.
      • 
          
    • Ficheros de más de 512 KB. Todo esto se puede cambiar en Opciones.
      • 
        
    
        
    Lo omitido sigue apareciendo en el árbol, así la IA sabe que existe.
    
      
    

      
    
        
    Lo que conviene saber
    
        
      
          
    • No hay servidor: el navegador habla directamente con GitHub.
      • 
          
    • Sin token, GitHub permite unas 60 consultas por hora. Cada repo gasta tres.
      • 
          
    • Para repos privados, cada fichero cuenta como una consulta (hasta 5000 por hora).
      • 
          
    • Los tokens se cuentan de forma aproximada, a unos cuatro caracteres por token.
      • 
          
    • Crea también un fichero .gittomdignore en el repo para excluir rutas siempre.
